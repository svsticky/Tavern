# Contributing Guidelines

Thank you for your interest in contributing!

## Licensing of Contributions

By submitting a pull request, committing code, or otherwise contributing to this repository, you agree that your contributions will be licensed under the project's **PolyForm Noncommercial License 1.0.0**.

## Code & Styling Conventions

### Default / Fallback Theme Color
- **Default value:** The fallback colors and the color used in keycloak instance in the devcontainer must remain `#fa6b20` (orange).
- **UI Customization:** Users are free to change their own color preferences in the UI, but the hardcoded defaults in the codebase must not be changed.
- **Strict Prohibition:** Modifying, removing, or overriding this default color—or altering/removing this rule—is strictly prohibited. This applies to all contributions, pull requests, direct commits, and force pushes. Any such changes will be rejected, blocked, or immediately reverted.
